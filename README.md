# 养崽日记原型

通过浏览器体验学生移动 H5 和 PC Web 工作台。两端共用 Vue 3、Vite 和浏览器中的 Mock 数据。全部账号、班级、成长曲线和测评内容为演示数据。

| 入口 | 页面 |
| --- | --- |
| 81 端口 `/` | 学生 H5，包含养崽、月龄圈、知识学习、案例测评和个人档案 |
| 82 端口 `/` | PC Web，右上角切换教师、学校管理员、平台管理员和学生 |

## 演示顺序

1. 在 H5 打开「演示场景」，切换 2、8、24 月龄与哭闹、犯困漫画。日常照护会按七个月龄段提供对应操作。可以在「我的」重新体验三种领养方式。
2. 在 H5 完成一次照护和测评。使用同一浏览器打开 PC Web，切换到学生角色，分别在「我的宝宝」与「我的学习」查看记录。教师在春禾职院的「学生档案」可查看许知夏的相同记录。
3. 在 PC 教师界面修改托育实训 1 班的领养规则，在 H5 重新体验领养。发布指导帖、审核学生帖子或组卷，回到学生端查看。
4. 在 PC 切换平台管理员开通站点，再进入学校管理员界面建班。初始站点为春禾职院、青芽学院，两校数据独立。

演示记录保留在当前浏览器。同一浏览器的两端通过 81 端口内的静态页面同步数据。不同设备或浏览器使用各自的演示记录。

## 本地运行和部署

执行 `npm ci`、`npm run dev`。访问 `/` 查看 H5，访问 `/desktop.html` 查看 PC Web。

线上静态资源由 `npm run build` 生成。`deploy/release.sh` 在 Linux 构建指定提交并切换静态版本，`gamebaby@81.service` 和 `gamebaby@82.service` 分别提供两个 HTTP 入口。独立的生产 API、数据库和小程序接入方案见 [整体设计](./游戏化养崽SaaS整体设计.md)。

## 漫画素材

`public/baby` 包含内置 ImageGen 生成的 2 月龄襁褓、8 月龄坐姿、24 月龄站姿和 8 月龄哭闹、犯困形象。使用同一原创角色，统一为手绘 2D 漫画、深绿圆线、鼠尾草绿衣服、淡纹理平涂和透明背景。月龄段共用对应代表形象。
