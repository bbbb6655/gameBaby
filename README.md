# 养崽日记原型

通过浏览器使用学生移动 H5 和 PC Web 工作台。两端使用 Vue 3 和 Vite，后端使用 Node.js 22、Express、TiDB 和 Redis。账号、学校、班级、审核与上传记录由后端保存，养崽和测评使用教学演示规则及样例内容。

| 入口 | 页面 |
| --- | --- |
| 81 端口 `/` | 学生 H5，包含养崽、月龄圈、知识学习、案例测评和个人档案 |
| 82 端口 `/` | PC Web，右上角切换教师、学校管理员、平台管理员和学生 |

## 开通和审核流程

1. 系统管理员在 PC 开通学校，并通过手机号设置学校管理员。已有账号保留原实名、昵称和密码。新账号在创建结果里获取初始密码。
2. 系统或学校管理员预建「学校 → 专业 → 届别 → 班级」。学校管理员给教师分配负责的班级。
3. 学生在注册页填写手机号、密码、实名和昵称，并一次选齐学校、专业、届别、班级。注册使用页面展示的演示短信验证码 `1234`，无需实际发送短信。注册同时提交入校和入班申请。学校管理员通过入校申请后，系统管理员、同校学校管理员及所选班的教师均可审核入班。
4. 入班审核通过后，两端开放学生空间。H5 可领养、照护和测评，PC 使用同一账号查看记录。账号页面可以修改自己的手机号、昵称和密码。
5. 管理员可按班级粘贴学生的手机号、实名、昵称三列批量录入，预录时视为管理员确认加入。名册支持筛选新录入学生并导出 Excel 可打开的 CSV。手机号只对应一个账号，审核通过的账号只能归属一所学校。

实名字段以加密形式存入 TiDB，仅在教师查看其负责班级的入班申请或名册时返回。系统及学校管理员按手机号、昵称审核和导出。后台「账号管理」支持查询下级账号、修改手机号和重置密码。系统管理员管理学校管理员、教师和学生，学校管理员管理本校教师和学生，教师管理负责班级的学生。重置后，后台显示临时密码，该账号的旧会话失效。

## 存储

TiDB 专库 `gamebaby` 包含学校、专业、班级、用户、班级成员、教师班级分配、审核历史、文件元数据和学生演示学习状态。Redis 保存登录会话。服务器上传目录用 `/opt/gamebaby/uploads`，按 `avatars` 和 `materials` 分类。磁盘文件采用随机 ID，下载经账号接口校验访问范围，文件原名和范围保存在 TiDB。

## 本地运行和部署

复制 `.env.example` 为 `.env.local` 并填入专库连接信息、Redis 地址和 32 字节十六进制 `PROFILE_KEY`。使用有建表权限的项目数据库账号执行 `server/schema.sql`。首个系统管理员由主机管理者通过 `npm run bootstrap-admin -- <账号信息 JSON 路径>` 创建，文件包含 `phone`、`nickname`、`realName`、`password`。

依次执行 `npm ci`、`npm run api` 和 `npm run dev`。访问 `/` 查看 H5，访问 `/desktop.html` 查看 PC Web。`npm run build` 生成两端静态文件。服务器部署前把实际连接配置写入 `/opt/gamebaby/api.env`，使用 `deploy/release.sh` 构建指定提交。`gamebaby-api` 统一在 81 和 82 提供页面及 API，检查两个入口、版本以及 TiDB 和 Redis，失败时恢复到旧服务。完整业务功能的原始规划见 [整体设计](./游戏化养崽SaaS整体设计.md)。

## 漫画素材

`public/baby` 包含内置 ImageGen 生成的 2 月龄襁褓、8 月龄坐姿、24 月龄站姿和 8 月龄哭闹、犯困形象。使用同一原创角色，统一为手绘 2D 漫画、深绿圆线、鼠尾草绿衣服、淡纹理平涂和透明背景。月龄段共用对应代表形象。
